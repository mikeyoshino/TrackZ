Implementation contract

This file is a visual reference, not production HTML. The shipped page remains native MAUI XAML.

1
One primary action

The same button changes between Start and Continue. Never render two lime actions.

2
Action-first hierarchy

Header → hero → motivation → Train again → Recent momentum. Do not collapse Home to Resume only.

3
Truthful metrics

Weekly goal, streak, Level/XP, Last, and Best come from authoritative cached or refreshed progress.

4
User-controlled training

Continue opens Today’s workout. Train again repeats known history. No prescribed exercise.

5
Native system

Use TrackZ semantic colors, 4-point spacing, shared typography, at least 44-point targets, Dynamic Type, Reduce Motion, and EN/TH resources.

6
State visibility

Train again is hidden while active. Motivation and momentum are hidden when no authoritative snapshot exists.
