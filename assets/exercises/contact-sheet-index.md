# Contact-sheet source/index

No contact sheet is approved or embedded in this repository. Once all 48 dedicated PNGs are generated, build the contact sheet only as a review aid and present it to the product owner/anatomy reviewer. It cannot change any record from `Draft`.

Use `catalog.json` order as the contact-sheet order: Chest, Back, Shoulders, Arms, Legs, then Core; eight cards per body part. The source filename for each card is its `imagePath` in the manifest.
